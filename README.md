# 高業領航

證券商高級業務員備考站，整合三科歷屆題庫、分科複習、圖像記憶卡與模擬考。

## 使用方式

部署至 GitHub Pages 後，從 `index.html` 開始使用。題庫與記憶卡資料位於 `data/`，樣式與前端程式位於 `css/`、`js/`。

啟用方式：GitHub repository → **Settings** → **Pages** → **Deploy from a branch** → 選擇 `main` 與 `/(root)`。

## 備考範圍

- 投資學、財務分析、證券交易相關法規與實務
- 105–115 年共 37 回歷屆題庫
- 每科 1,850 題；全科共 5,550 題
- 考試時程、教材與法規資訊以證基會最新公告為準
